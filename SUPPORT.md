# Getting Support

Thanks for using the Physio ecosystem. Here is how to get help.

## Documentation first

- Each package has reference documentation and vignettes (rendered on its
  pkgdown site and on the [x-biosignal r-universe](https://x-biosignal.r-universe.dev)).
- In R, use the built-in help: `?functionName`, `help(package = "PhysioCore")`,
  and `browseVignettes("PhysioCore")`.

## Questions and usage help

- Search existing issues on the relevant package repository under
  [github.com/x-biosignal](https://github.com/x-biosignal) — your question may
  already be answered.
- For "how do I ...?" questions, open a **Question** issue on the relevant
  package's repository, or start a Discussion if the repository has Discussions
  enabled.

## Bug reports and feature requests

- Open an issue on the specific package's repository (e.g.
  `x-biosignal/PhysioECG` for an ECG issue).
- For bugs, please include a **minimal reproducible example**, your
  `sessionInfo()`, and the package version. Small, self-contained examples are
  the fastest path to a fix.

## Contributing a fix

If you would like to contribute code, see [CONTRIBUTING.md](CONTRIBUTING.md) and
[GOVERNANCE.md](GOVERNANCE.md). All participation is subject to the
[Code of Conduct](CODE_OF_CONDUCT.md).

## Security issues

Do **not** file security vulnerabilities as public issues. Follow the private
process in [SECURITY.md](SECURITY.md).
